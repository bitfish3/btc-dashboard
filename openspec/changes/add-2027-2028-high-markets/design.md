## Context

主站与 probs 子站已共享 2027 的两条官方 Polymarket 合约。2026 页包含上下触价曲线与区间概率；它的年份和成交量权重不能直接移植到其他年份。

## Goals / Non-Goals

目标：主站按年份展示真实上方档位与概率，子站按年份展示详情，复用现有部署和请求调度。

不生成目标价预测、不跨年合并、不使用稀疏或起始日期不同的合约推导年度最高价分布；资产占比仍是唯一模型参数。

## Decisions

- 复用 `/api/forecast/2027`，新增 `/api/forecast/2028`。后台将采集函数参数化，市场白名单、截止、KV、单次并发按年隔离；2027 既有契约保持兼容。
- 接纳的是从各合约开市到美东该年末的上方触价概率。2027 年末对应 2028-01-01 05:00 UTC；2028 对应 2029-01-01 05:00 UTC。必须验证子市场，而不是父事件日期。
- 没有已验证白名单合约时返回 `not_listed` 和空市场；上游错误返回 `unavailable`，有效旧快照最多保留一天且标记。两种空状态不可互相冒充，空值不显示为 0%。
- 主站两个独立任务，两个价位卡片组；复用现有 prob-tile 外观，窄屏按年份堆叠。保留 2027 DOM 入口并增加 2028，详情链接指向 probs 同域不同 year query。
- 主站和子站每年按用户要求固定 $100k / $150k / $200k / $250k 四档。只给有真实报价的档位绘制绝对概率条、成交量与获取时间；其余用 `-- / 暂无报价`。2026 页加入年份导航，既有年度上下行图保留。

## Risks / Trade-offs

- 未找到某年份真实市场 → 完成对应 API、页面、空状态，不外推概率；后续核验新合约后加入白名单。
- 长期市场成交稀少 / 各档位开市时间不同 → 明示触价口径、成交量；不对两档报价拟合最可能最高价。
- 上游超时 → 保留五秒正文截止、十分钟缓存、一天 last-good；年份和主站报价独立。
- 旧客户端 → 2027 函数及 API 保持可用。部署先 Worker，后主站；回滚使用本次之前提交及 Worker 版本。
