## Why

本周期目标目前仅有一行 2027 触价数据，缺少与 2026 跌破概率一致的价位展示及 2028 入口。用户需要在主站快速比较两年上行概率，并到既有概率子站查看完整口径。

## What Changes

- 主站加入 2027 / 2028 高点概率卡片，每年固定 $100k / $150k / $200k / $250k 四档，链接对应年份的 probs 子站详情；缺报价以 `-- / 暂无报价` 表示。
- 预测 API 按年份隔离合约、截止时间、缓存和失败状态，只接纳可核验的一手合约。
- 子站增加年份导航和上行概率详情。缺失合约明确显示暂无可验证合约，不用其他年份或模型外推补数。
- 保留唯一配置参数及默认 1.5%，概率不参与目标价或资金需求计算。

## Capabilities

### New Capabilities

- `multi-year-high-markets`: 2027 / 2028 上方触价概率与跨站年份导航，包含数据边界和空状态。

### Modified Capabilities

无。

## Impact

主站 HTML、预测适配器、调度/渲染和浏览器测试；既有 fuckbtc-probs Worker 的年份 API、详情页和测试。沿用现有 CF Worker/Pages 与 KV，不新增基础设施或秘密。
