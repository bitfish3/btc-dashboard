## Why

用户要求吸收参考站的本周期目标与全球可配置资产占比框架，并加入对应资金流需求。现有 BTC 看板展示当前指标与成本锚，但没有把配置占比、目标价格、市值增量和资金需求联动起来的测算模块。

## What Changes

- 新增“本周期目标”区及导航入口，沿用现有版式，提供可编辑的目标价与资产配置情景。
- 保留 1%、1.5%、2%、2.5%、3%、5% 占比档位，按输入资产池/供给计算目标市值与币价。
- 计算新增市值与净流入模型区间，并换算年均/月均资金需求。市值增量与净流入严格分开，不能按 1:1 冒充资金需求。
- 复用已经验证的当前币价，不增加网络请求；报价缺失/过期时只显示独立于当前价的目标值。
- 参考站的 $17 万目标、15–20 倍市值放大参数及 2–3 年期限用作可编辑情景，不作为预测或事实声明；全球资产池默认 $300T、供给默认 20M BTC，明确为假设。

## Capabilities

### New Capabilities

- `cycle-target-funding-model`: 配置占比、目标价、市值变化与资金需求的参数化计算及可访问呈现。

### Modified Capabilities

无主 specs 变更；沿用既有 runtime 的数据时效边界。
